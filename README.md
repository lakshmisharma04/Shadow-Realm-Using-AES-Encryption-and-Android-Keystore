# Shadow Realm — Multiplayer Social Deduction Game

Shadow Realm is a multiplayer social deduction game built with Android and Java, supported by a Spring Boot backend and MySQL database.

## Technologies Used
- Android (Java)
- Spring Boot
- MySQL
- Retrofit

## Project Structure
- `Android/` — Android application
- `Backend/` — Spring Boot backend

## Setup
Configure the required database connection and secret environment variables before running the backend. Open the Android project in Android Studio to build and run the application.
