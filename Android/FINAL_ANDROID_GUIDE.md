# Shadow Realm Android — Final

Open this folder in Android Studio.

Backend must be running on your computer at port 8080.
Android Emulator uses `http://10.0.2.2:8080/`.

For a physical phone, replace `BASE_URL` in `RetrofitClient.java` with your computer's LAN IP and keep both devices on the same Wi-Fi.

Use the online buttons for the real server game. `SOLO PRACTICE • OFFLINE DEMO` is only a fallback demonstration and does not use the backend.
